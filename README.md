# AI Explorer

**AI Explorer — каталог AI-сайтів**

Невеликий веб-проєкт (тестове завдання) на **React + TypeScript + Vite**, який отримує дані про AI-сервіси через публічний **FreeSerp API** без API key та реєстрації.

## Мета

Дати зручний спосіб знаходити AI-сервіси та швидко переглядати інформацію про них: опис, категорію, рейтинг домену (DR) та дату появи сайту.

## Цільова аудиторія

* розробники й продакт-менеджери, які шукають AI-інструменти;
* засновники й маркетологи, які досліджують AI-сервіси;
* дослідники та ентузіасти AI.

## Основний функціонал

* пошук AI-сайтів;
* фільтрація за AI-категоріями;
* сортування результатів;
* відображення інформації про AI-сервіс;
* рейтинг домену (DR);
* дата появи сайту;
* завантаження додаткових результатів через **Load More**;
* стани завантаження, помилки та відсутності результатів.

## Сторінки

| Сторінка           | Маршрут   | Опис                                                         |
| ------------------ | --------- | ------------------------------------------------------------ |
| Home / Каталог     | `#/`      | головний блок, пошук, фільтри, сортування, картки, Load More |
| About / Про проєкт | `#/about` | мета проєкту, джерело даних та пояснення основних параметрів |

## Джерело даних

Для отримання інформації використовується публічний **FreeSerp API**.

Основні параметри запиту:

* `q` — пошуковий запит;
* `ai_categories` — категорія AI-сервісу;
* `dr_min` — мінімальний Domain Rating;
* `sort` — сортування за релевантністю, DR або датою;
* `order` — напрямок сортування;
* `size` — кількість результатів;
* `from` — зміщення для завантаження наступних результатів.

`went_live` — дата першого підтвердження того, що сайт працює.

## Структура проєкту

* `src/api.ts` — запити до FreeSerp API;
* `src/pages/Catalog.tsx` — сторінка каталогу;
* `src/pages/About.tsx` — сторінка про проєкт;
* `src/components/SiteCard.tsx` — картка AI-сайту;
* `src/hooks/useDebounced.ts` — затримка пошуку;
* навігація через `#/` і `#/about` без `react-router`.

## Запуск

```bash
npm install
npm run dev
```

Після запуску проєкт буде доступний за адресою:

`http://localhost:5173`

Для перевірки production-збірки:

```bash
npm run build
```

Збірка створюється у папці `dist`.

## Вимоги

* Node.js 18+
* npm

## Примітки

У режимі розробки запити до FreeSerp API проходять через проксі Vite.

Якщо проєкт розгортається на статичному хостингу, де немає проксі, потрібно налаштувати `VITE_API_BASE` відповідно до способу розгортання.
